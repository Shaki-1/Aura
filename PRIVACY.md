# Privacy

AURA is designed as a local-first Windows accessibility assistant prototype.

## Local-First Processing

AURA runs accessibility support and detection locally on the user's device. Active application detection and Windows UI Automation metadata are processed through local scripts and Electron IPC.

## Screenshots

AURA does not upload screenshots. The current prototype does not require screenshot upload for accessibility profiles, overlay filters, or reading-area detection.

## Cloud Storage

AURA does not use cloud storage for user activity, accessibility profiles, scan results, screenshots, or detection data.

## User Control

Screen enforcement is activated by the user and can be stopped from the application. The emergency shortcut `Ctrl + Alt + A` stops enforcement immediately.
