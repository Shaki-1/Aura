# GDPR

AURA is prototype software intended for demonstration and testing of local accessibility support.

## Data Processing

AURA is designed to minimize personal data processing. The app uses local active-window detection and Windows UI Automation metadata to support accessibility profiles and overlay behavior.

## Local Operation

The prototype does not require cloud processing, screenshot upload, or cloud storage for its current accessibility features.

## User Control

The user controls when screen enforcement is activated. Support can be stopped from the app, and the emergency shortcut `Ctrl + Alt + A` immediately stops enforcement.

## Notes

Organizations evaluating AURA should perform their own privacy and compliance review before production deployment.
