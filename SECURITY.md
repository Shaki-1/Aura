# Security

AURA is designed for local execution on Windows.

## Local Execution

The current prototype runs local Electron code and local PowerShell scripts for active-window detection and Windows UI Automation scanning. It does not require screenshot upload, cloud processing, or cloud storage for current features.

## Responsible Disclosure

If you discover a security issue, please report it responsibly to the project maintainer before public disclosure.

When reporting, include:

- A clear description of the issue.
- Steps to reproduce.
- Potential impact.
- Suggested mitigation, if known.

## Scope

Security review should include Electron configuration, preload APIs, PowerShell scripts, packaging, and local file handling.
