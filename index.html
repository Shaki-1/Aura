What is AURA

AURA is a local-first Windows accessibility assistant that helps make desktop work more comfortable through visual support profiles, screen overlay guidance, and local detection.

Accessibility modes

  • Color Blind: contrast and color separation support.
  • Eye Strain: warmer, softer comfort filters.
  • Low Vision: stronger focus and reading-area visibility.

Privacy

  • Local-first processing on your device.
  • No screenshots uploaded or stored.
  • Support is user-controlled and can be stopped instantly.

Detection

  • Uses Windows accessibility APIs when available.
  • Experimental reading-area detection is still improving.
  • Falls back to general profile support when needed.

Shortcut

Ctrl + Alt + A

Immediately stops active screen enforcement.
