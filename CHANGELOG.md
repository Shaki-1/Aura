# Changelog

## 0.3.0

Teacher demo release.

### Added

- Accessibility profiles for Color Blind, Eye Strain, and Low Vision support.
- Transparent local overlay support for visual accessibility filters.
- Local-first active application monitoring.
- Experimental reading-area detection using Windows UI Automation metadata.
- Privacy, GDPR, disclaimer, security, and testing documentation.

### Notes

- No screenshots are uploaded.
- No cloud processing is required for current prototype features.
- Reading-area detection is experimental and continues to be improved.
